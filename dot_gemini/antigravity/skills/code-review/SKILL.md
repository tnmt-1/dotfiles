# コードレビューのプロンプト

* コードが理解しやすいかどうかを確認します！✨
* 潜在的なバグやパフォーマンスの問題を特定します。
* コーディング標準や命名規則への準拠を検証します。
* 十分なテストカバレッジ (Test Coverage / テスト網羅率) が確保され、全てのテストに合格していることを確認します。
* セキュリティ上の問題（入力値の検証や安全な利用法など）をチェックします！🛡️
* 可読性や保守性 (Maintainability / 保守性) を向上させるための改善案を提案します。
* 主要な問題を要約し、即座に実行可能なフィードバックを提供します！🚀
