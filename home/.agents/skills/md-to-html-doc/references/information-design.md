# 情報設計の基準

## 冒頭

- 最初の画面に、資料の目的を1〜3文で書いたリード文と、主要な結論の要点パネルを置く
- 要点パネルの各項目は、ラベル、結論を1行、根拠や条件を2〜3行で書く
- 読み手が複数いれば、それぞれが読む範囲を冒頭に示す
- 要望の有無や前提の欠落のような、資料全体にかかる注意は冒頭に書く

## 並べる順

- 目的と結論 → 現状 → 前提と用語 → 判断すること → 詳細 → 参考、を基本にする
- 判断を求める資料では、判断する人が読む部分を前に、判断のあとで詰める部分を後ろに置く
- 決める順番に意味があるときは、ステップ表示で順番を示す
- 用語の定義は、その用語を最初に使う節の直前に置く

## 統合と分割

- 同じ対象を別の角度から書いた節は、1つにまとめる。例: 構成図と、案ごとに変更するシステムの表は、案を選ぶと構成図が変わる1つの部品にまとめる
- 1つの節に、種類の違う情報（比較、注意、案）が混ざっていたら、表現ごとに分ける
- 一覧の表と、各項目の詳細が両方あるときは、一覧から詳細へリンクする

## 元の文書の順のまま（作り直しが必要な状態）

- 節の順が、元の文書の見出しの順と同じ
- すべての節が、同じ部品（カードの並び、見出しと箇条書き）でできている
- 冒頭に結論がなく、背景から始まる
- 文章と箇条書きだけの節が半分を超える
- 図表が、元の文書のMermaidを描き直しただけで、配置と強調が元のまま

## 優先度の見せ方

- 結論と案は、色の付いた面か太い枠で示す
- 注意と未確認の事項は、本文と分けた注意喚起のパネルにする。注意と未確認は別のパネルにする
- 補足は、小さい文字か、折りたたみにする
- 場合分けの片方だけに関係する情報（例: 別の案が選ばれた場合）は、折りたたみにする

## 追跡できるようにする

- 各節に「元の文書の節: ◯◯」を小さく添える
- 元の文書の番号（決めることの番号など）は変えずに使う
- 長い資料には目次を置く。幅の広い画面では左に固定し、狭い画面では冒頭に並べる
