# HTMLを書くときの注意

## レイアウト

- グリッドの列は `minmax(0, 1fr)` にする。`display: grid` の要素は、列を指定しないと、中の幅の広い図や表に合わせて広がり、狭い画面でページ全体がはみ出す
- 幅の広い図、表、タイムラインは、`overflow-x: auto` の枠に入れ、枠の中で `min-width` を付ける
- 表は、狭い画面で列が縮み、1文字ずつ折り返す。幅640px以下では、表に `min-width`（目安560px）を付けて枠の中で横にスクロールさせる
- 狭い画面で変えるレイアウトを、インラインの `style` 属性で書かない。メディアクエリで上書きできなくなる
- 見出しの前に番号の丸印を付けるときは、折り返しを止め（`flex-wrap: nowrap`）、見出しに `min-width: 0` を付ける。止めないと、番号だけが別の行に残る

## SVG

- 文字の色や線の色は、CSSのクラスと色のトークン（`var(--ink)` など）で付ける
- 箱の幅は、全角1文字を文字サイズと同じ幅として計算する。入らないときは2行に分ける
- 矢印の `marker` 要素に付けるidは、SVGごとに別の名前にする
- `viewBox` の下端は、最後の要素に合わせる。余白が残ると、図の下に空白ができる
- 文字サイズは、画面に表示したときの大きさで、デザインシステムの最小の文字サイズを下回らないようにする。狭い画面では縮めず、枠の中で横にスクロールさせる

## 表示を確かめる

- ヘッドレスのChromeは、幅500px未満のウィンドウを作れない。`--window-size=390,...` で撮ると、幅500pxで描画した画面の左側が切り取られ、はみ出しているように見える。幅375pxはiframeに入れて撮る（`scripts/render.sh` がそうしている）
- スクリーンショットは、ページ全体を撮ってから縦に分けて見る。1枚のままだと縮小されて文字が読めない
- はみ出しの検査で、枠の中で横にスクロールする要素は問題にしない
