# 完成条件

## 情報設計

- Markdownの見出しと文章を、そのままHTMLへ置き換えただけのものではない
- 最初の画面で、資料の目的と主要な結論が分かる
- 情報の重要度と関係が、配置、色、大きさで分かる
- 情報の種類ごとに、合った図表が選ばれている。文章と箇条書きだけの節が半分を超えない
- 内容に合わない図表やカードを足していない
- 同じ部品の繰り返しで、ページ全体ができていない

## 正確さ

- 元の文書にない事実、仕様、数値、分岐を足していない
- 条件、例外、注意、未確認の事項、コード、設定値が、すべて残っている
- 各節から、元の文書の節をたどれる

## デザイン

- デザインシステムがあれば、その色、文字、余白、角丸に従っている
- 色だけで意味を伝えていない。状態には文言を添えている
- 装飾のためのグラデーション、影、アニメーション、アイコンがない
- 長い資料に目次がある

## 表示

- 幅1280pxと幅375pxのスクリーンショットで、文字の重なり、箱からはみ出した文字、切れた図がない
- `scripts/render.sh` のはみ出しの検査で、表示幅と文書幅が同じ
- 画面を操作する部品があれば、初期の状態で正しく表示される
