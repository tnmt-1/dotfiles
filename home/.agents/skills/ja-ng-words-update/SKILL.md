# 直訳造語辞書の更新

辞書 `~/.claude/hooks/ja-ng-words.tsv` は、pi拡張 `~/.pi/agent/extensions/japanese-writing-hooks.ts` とClaude Codeのフック `~/.claude/hooks/japanese-writing-hook.ts` が共有している。
辞書の語は毎回プロンプトに入り、回答に出ると書き直しが求められる。
誤った語を入れると正しい文章まで書き直しの対象になるので、迷う語は入れない。

追加はユーザーに確認せずに行い、最後に追加した語を報告する。

## 手順

1. `bun ~/.pi/agent/skills/ja-ng-words-update/scripts/extract.ts` を実行する。前回の実行以降（初回は直近14日）の回答から日本語の地の文を取り出し、分割したファイルのパスを表示する。
2. `~/.claude/hooks/ja-ng-words.tsv` を読み、登録済みの語を把握する。
3. 分割したファイルごとに読み取り専用のサブエージェントを並行で起動し、下の「サブエージェントへの依頼」を渡す。ファイルが1つなら自分で読む。
4. 返ってきた候補を、下の「追加の基準」で絞る。
5. 残った語を辞書の末尾に追記する。形式はタブ区切りで `語	言い換え	<英語の原語> の直訳（YYYY-MM-DD 自動追加）`。
6. `bun ~/.pi/agent/skills/ja-ng-words-update/scripts/extract.ts --done` を実行し、今回の時刻を記録する。候補がなかったときも実行する。
7. 追加した語、言い換え、出現した行を1つずつ報告する。追加しなかった候補は、理由と一緒に短く挙げる。取り消すには辞書の該当行を消せばよいことも書く。

## サブエージェントへの依頼

```
<ファイルのパス> を読み、英語の技術用語や慣用句を語ごとに直訳して作った不自然な日本語の語を探してください。
例: 生値（raw value）、熱い経路（hot path）、柔らかい削除（soft delete）、裸の値（bare value）。

対象外:
- 定着した訳語（遅延評価、論理削除、正常系など）
- 固有名詞、コードの識別子、ファイル名
- 普通の日本語、誤字、表記ゆれ、語順や文体の問題

見つけた語ごとに、次のタブ区切りの1行を返してください。見つからなければ「なし」とだけ返してください。
語	言い換え（その分野の定訳、カタカナ語、または説明的な言い方）	英語の原語	出現した行をそのまま
```

## 追加の基準

次をすべて満たす語だけを追加する。

- 辞書に同じ語がない。
- 出現した行が、抽出したファイルに実際にある（`grep -F` で確かめる）。「」で括って語について話している行しかない語は、使用ではないので数えない。
- その分野に定訳かカタカナ語があり、言い換えがそれになっている。言い換えが定まらない語は、何を表す値か、何の操作かを書く言い方にする。既存の「生値」の行を参考にする。
- 部分一致で普通の語に当たらない。辞書は部分一致で検査する。ただし漢字で始まる語は、直前も漢字なら熟語の一部とみなして無視する。抽出したファイル全体を `grep -F` で検索し、造語として使われていない一致があれば、より長い形で登録するか、追加しない。
- 2文字以下の語は、上の確認で一致がすべて造語の使い方だったときだけ追加する。
