# 書籍との差

ユーザーが、推敲結果は手元の第3版と違う、と指摘した規則を書く。ここにある ID は、rules.md の同趣旨の規則より優先する。

## U-001

- 優先する対象: JTF 4.2.7 コロン
- 対象: 共通
- 強度: 必ず
- 規則: 「例」「注」のような語のあとに続けるコロンは、半角のコロンと半角の空白で書く。
- 修正前: 例：`user-pool-create.md`
- 修正後: 例: `user-pool-create.md`
- 例外: 引用、コード、画面に出る文字列は、元の表記のまま残す。

追記する形:

```markdown
## U-001

- 優先する対象: 2-1-014
- 対象: 共通
- 強度: 必ず
- 規則: ユーザーが言った直し方を一文で書く。書籍の文は写さない。
- 修正前:
- 修正後:
- 例外:
```
